# Custom Functions

Funciones Open WebUI versionadas para el proyecto de chat personal.

La Function principal es `multi_model_conversations_v2.py`; ver la guia en `docs/custom-functions/multi_model_conversations_v2.md`.

- `easysearch.py`: filtro de busqueda web comunitario. Se versiona con un parche local para uso global y disparo natural en espanol; ver `docs/custom-functions/easysearch.md`.
